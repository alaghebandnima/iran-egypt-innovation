# بررسی نظام‌های نوآوری ایران و مصر

مقایسهٔ ایران و مصر در بازهٔ **۲۰۰۵ تا ۲۰۲۴** با **۵۱ شاخص منبع و ۴ شاخص محاسبه‌شده**، برای درس مدیریت فناوری و نوآوری دانشگاه صنعتی امیرکبیر.

**[نسخهٔ آنلاین](https://innovation.alaghebandnima.ir) | [English](README.md) | [منابع و روش‌ها](docs/DATA_AND_METHODS.md)**

## امکانات

نمودار و جدول مقایسه، پوشش داده‌ها، رویدادهای تاریخی، آزمایش تخمین با پنهان‌کردن عمدی داده‌های معلوم، دریافت اکسل، گزارش تحلیلی دو کشور و گزارش متودولوژی در برنامه قرار دارند. رابط فارسی و انگلیسی، حالت روشن و تیره و چیدمان موبایل پشتیبانی می‌شوند.

دستیار متصل به **اولاما** به‌صورت خودکار پاسخ کوتاه و مبتنی بر شاخص انتخاب‌شده می‌دهد. اعداد را پایتون محاسبه می‌کند و مدل کوئن۳ چهارمیلیاردی توضیح می‌نویسد؛ فقط پاسخ نهایی نمایش داده می‌شود. دادهٔ منبع و تخمین پروژه جدا هستند. کنترل پاسخ، تضمین درستی همهٔ تفسیرهای مدل نیست.

## اجرای برنامه

پایتون ۳٫۱۲ و برنامهٔ رسمی [اولاما](https://ollama.com/download) را نصب کنید. در پوشهٔ پروژه، این دستورها را در پاورشل ویندوز اجرا کنید:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
ollama pull qwen3:4b-instruct
.\.venv\Scripts\python.exe -m streamlit run app/dashboard.py
```

نشانی برنامه **http://localhost:8501** است. اولاما باید روی نشانی محلی `127.0.0.1:11434` اجرا باشد؛ اگر سرویس آن فعال نیست، `ollama serve` را اجرا کنید. دانلود اولیهٔ مدل حدود ۲٫۵ گیگابایت است. فایل‌های مدل در گیت‌هاب قرار ندارند. راه‌اندازهای `run.ps1` و `run.sh` نیز ارائه شده‌اند؛ راهنمای مک و لینوکس در صفحهٔ انگلیسی آمده است.

پرسش‌های نمونه: «پتنت در ۲۰۲۴ چقدر است؟»، «این شاخص چه محدودیتی دارد؟» و با انتخاب شاخص تحقیق‌وتوسعه «داده موجود است؟». در سرور دو‌هسته‌ای با رم ۴ گیگابایت، میانگین چهار آزمون فارسی حدود ۸۵ ثانیه بوده است؛ زمان دستگاه‌های دیگر و پرسش‌های دیگر متفاوت است. پاسخ‌های تکراری از حافظهٔ پاسخ بازیابی می‌شوند.

## کنترل کیفیت

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s app/tests -q
.\.venv\Scripts\python.exe scripts/audit_active_data.py
```

پروژه ۵۹ آزمون دارد. داده‌های قرمز، تخمین پروژه‌اند؛ آن‌ها مشاهدهٔ منتشرشدهٔ منبع نیستند. رتبه‌های ناموجود نوآوری بازسازی نمی‌شوند و هم‌زمانی یک رویداد با تغییر شاخص، علت را ثابت نمی‌کند. جزئیات منابع، استثناهای پوشش و بازتولید در راهنمای انگلیسی و فایل منابع آمده‌اند.

## اعضای پروژه

**نیما علاقه‌بند و امیرعباس عموزاده**؛ استاد درس: **خانم دکتر سارا سلیمی نمین**؛ همراهان آموزشی: **نازنین ناظم و ارسلان جباری**. دانشکدهٔ مدیریت، علم و فناوری، دانشگاه صنعتی امیرکبیر.

این مخزن، نسخهٔ مخصوص انتشار عمومی است. فایل‌های ورد، اطلاعات ورود، ابزارهای اتصال سرور، محیط‌های نصب‌شده و مدل سنگین منتشر نمی‌شوند. فایل‌های اجرایی فعلی پروژه تغییر نکرده‌اند. برای فونت و داده‌ها به [اعلان منابع و حقوق](THIRD_PARTY_NOTICES.md) مراجعه کنید.
